# IDProtoSim
A protogen simulator made by Illusionary Dynamics (me).
This tool is for simulating expressions for protogens using 2 HUB75 32*64 P3.0 Panels. Updates for 7219 and et cetra will come later. It runs on HTML so compatibility is wide.
It features blinking, eye locating, breathing, and a few more functions. It is just a little tool I made so that I can preview how my protogen will look like when complete.
Upload any emotes you want using the built-in upload function. PNG format. Black background and white mouth, eye, nose. BIN files are accepted as well. It will automatically locate the eye and make the animations. Transition between emotes are done in a fluid-simulated animation.
